# Citizen Protein Project — domain glossary

Single-context repo. Use these terms exactly; don't drift to synonyms.

- **Product**: one tested powder, identified by its lab code (`S16`, `#12`). Has a brand name, a type (whey / blend / plant), and one row of results per Test panel.
- **Test panel**: one lab analysis family: protein, sugar, amino acids, taurine, heavy metals, aflatoxins, pesticides, steroids/hormones, GC-MS scan.
- **Dossier**: the full per-Product detail view (the modal on the report pages).
- **Score**: a weighted ranking over protein content, amino quality, purity and safety record, recomputed live from slider weights.
- **BLQ**: below limit of quantification — not detected. Rendered as zero / "BLQ", never as a number.
- **Verdict**: the editorial ranking section crowning best overall / runner-up / avoid.
